# 阶段三交接文档：番剧管理

## 1. 阶段目标

完成番剧的增删改查、Bangumi 元数据对接、文件扫描与集数关联，使网站能浏览和管理番剧库。

**本阶段完成后系统状态**：
- 能通过搜索 Bangumi 添加番剧到库中（元数据自动拉取）
- 能关联本地视频文件目录并扫描出集数
- 番剧列表页展示所有已入库番剧（封面卡片网格、分页、搜索）
- 番剧详情页展示元数据和集数列表
- 能编辑、删除番剧

**本阶段不包含**：视频播放、播放进度记录（阶段四）

### 4.2 Bangumi API 服务 `services/bangumi.go`

Bangumi API 说明：
- 搜索：`GET https://api.bgm.tv/search/subject/{keywords}?type=2&responseGroup=small`（type=2 为动画）
- 详情：`GET https://api.bgm.tv/v0/subjects/{id}`
- 必须设置 User-Agent 请求头

```go
package services

import (
	"encoding/json"
	"fmt"
	"net/http"
	"net/url"
	"strings"
	"time"
)

const (
	bangumiBaseURL = "https://api.bgm.tv"
	bangumiUA      = "fan-web/1.0 (private anime library)"
)

// BangumiSearchItem 搜索结果项（简化后返回给前端）
type BangumiSearchItem struct {
	ID       int    `json:"id"`
	Name     string `json:"name"`
	NameCn   string `json:"name_cn"`
	Summary  string `json:"summary"`
	EpsCount int    `json:"eps_count"`
	Cover    string `json:"cover"`
}

// BangumiSubjectInfo 条目详情（简化后供内部使用）
type BangumiSubjectInfo struct {
	ID            int    `json:"id"`
	Name          string `json:"name"`
	NameCn        string `json:"name_cn"`
	Summary       string `json:"summary"`
	Cover         string `json:"cover"`
	TotalEpisodes int    `json:"total_episodes"`
}

// --- Bangumi API 原始响应结构（不导出） ---

type bgmSearchResponse struct {
	Results int            `json:"results"`
	List    []bgmSearchRaw `json:"list"`
}

type bgmSearchRaw struct {
	ID       int       `json:"id"`
	Name     string    `json:"name"`
	NameCn   string    `json:"name_cn"`
	Summary  string    `json:"summary"`
	EpsCount int       `json:"eps_count"`
	Images   bgmImages `json:"images"`
}

type bgmSubjectRaw struct {
	ID            int       `json:"id"`
	Name          string    `json:"name"`
	NameCn        string    `json:"name_cn"`
	Summary       string    `json:"summary"`
	Images        bgmImages `json:"images"`
	TotalEpisodes int       `json:"total_episodes"`
}

type bgmImages struct {
	Large  string `json:"large"`
	Common string `json:"common"`
	Medium string `json:"medium"`
	Small  string `json:"small"`
	Grid   string `json:"grid"`
}

// BangumiService 封装 Bangumi API 调用
type BangumiService struct {
	client *http.Client
}

func NewBangumiService() *BangumiService {
	return &BangumiService{
		client: &http.Client{Timeout: 10 * time.Second},
	}
}

// Search 搜索番剧
func (s *BangumiService) Search(keyword string) ([]BangumiSearchItem, error) {
	apiURL := fmt.Sprintf("%s/search/subject/%s?type=2&responseGroup=small",
		bangumiBaseURL, url.PathEscape(keyword))

	var resp bgmSearchResponse
	if err := s.doRequest(apiURL, &resp); err != nil {
		return nil, err
	}

	items := make([]BangumiSearchItem, 0, len(resp.List))
	for _, item := range resp.List {
		items = append(items, BangumiSearchItem{
			ID:       item.ID,
			Name:     item.Name,
			NameCn:   item.NameCn,
			Summary:  item.Summary,
			EpsCount: item.EpsCount,
			Cover:    toHTTPS(pickCover(item.Images)),
		})
	}
	return items, nil
}

// GetSubject 获取条目详情
func (s *BangumiService) GetSubject(id int) (*BangumiSubjectInfo, error) {
	apiURL := fmt.Sprintf("%s/v0/subjects/%d", bangumiBaseURL, id)

	var subject bgmSubjectRaw
	if err := s.doRequest(apiURL, &subject); err != nil {
		return nil, err
	}

	return &BangumiSubjectInfo{
		ID:            subject.ID,
		Name:          subject.Name,
		NameCn:        subject.NameCn,
		Summary:       subject.Summary,
		Cover:         toHTTPS(pickCover(subject.Images)),
		TotalEpisodes: subject.TotalEpisodes,
	}, nil
}

func (s *BangumiService) doRequest(apiURL string, target interface{}) error {
	req, err := http.NewRequest("GET", apiURL, nil)
	if err != nil {
		return err
	}
	req.Header.Set("User-Agent", bangumiUA)

	resp, err := s.client.Do(req)
	if err != nil {
		return fmt.Errorf("请求 Bangumi API 失败: %w", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode == http.StatusNotFound {
		return fmt.Errorf("未找到该条目")
	}
	if resp.StatusCode != http.StatusOK {
		return fmt.Errorf("Bangumi API 返回状态码 %d", resp.StatusCode)
	}

	return json.NewDecoder(resp.Body).Decode(target)
}

func pickCover(img bgmImages) string {
	if img.Large != "" {
		return img.Large
	}
	if img.Common != "" {
		return img.Common
	}
	return img.Medium
}

func toHTTPS(rawURL string) string {
	return strings.Replace(rawURL, "http://", "https://", 1)
}
```

### 4.3 文件扫描服务 `services/scanner.go`

扫描指定目录下的视频文件，通过正则匹配文件名提取集数编号。

**支持的文件名格式**（按匹配优先级）：
1. `[01]` / `[67]` — 方括号内的纯数字（最常见）
2. `- 01` / `-01` — 破折号后的数字
3. `EP01` / `EP 01` / `ep.01` — EP 前缀
4. `第12集` / `第12話` — 中文格式
5. `S01E12` — 季集格式
6. `12.mkv` — 扩展名前的数字（兜底）

**测试文件验证**：
```
[CheeseAni] Re：Zero kara Hajimeru Isekai Seikatsu 4th season Soshitsu-Hen [67][CR-WebRip HEVC AAC SRT][简繁内封].mkv
```
匹配过程：第一个模式 `\[(\d{1,3})\]` 扫描方括号：
- `[CheeseAni]` → 非纯数字，跳过
- `[67]` → 匹配！提取 67
- `[CR-WebRip HEVC AAC SRT]` → 非纯数字，跳过
- `[简繁内封]` → 非纯数字，跳过

结果：集数 = 67 ✓

```go
package services

import (
	"fmt"
	"os"
	"path/filepath"
	"regexp"
	"sort"
	"strings"

	"fan-web/models"
)

var videoExts = map[string]bool{
	".mkv": true, ".mp4": true, ".avi": true, ".mov": true,
	".flv": true, ".webm": true, ".ts": true, ".m4v": true,
}

// 按优先级排列的集数匹配模式
var epPatterns = []*regexp.Regexp{
	regexp.MustCompile(`\[(\d{1,3})\]`),          // [01] 或 [67]
	regexp.MustCompile(`-\s*(\d{1,3})\b`),         // - 01 或 -01
	regexp.MustCompile(`(?i)ep\.?\s*(\d{1,3})\b`), // EP01 或 ep.01
	regexp.MustCompile(`第\s*(\d{1,3})\s*[集話话]`), // 第12集
	regexp.MustCompile(`(?i)S\d{1,2}E(\d{1,3})\b`), // S01E12
	regexp.MustCompile(`(\d{1,3})\.(?:mkv|mp4|avi|mov|flv|webm|ts|m4v)$`), // 12.mkv（兜底）
}

// ScannerService 文件扫描服务
type ScannerService struct {
	rootPath string
}

func NewScannerService(rootPath string) *ScannerService {
	return &ScannerService{rootPath: rootPath}
}

// Scan 扫描目录，返回识别到的集数列表
func (s *ScannerService) Scan(dirPath string) ([]models.Episode, error) {
	fullPath := filepath.Join(s.rootPath, dirPath)

	entries, err := os.ReadDir(fullPath)
	if err != nil {
		if os.IsNotExist(err) {
			return nil, fmt.Errorf("目录不存在: %s", fullPath)
		}
		return nil, fmt.Errorf("读取目录失败: %w", err)
	}

	seen := make(map[int]bool)
	episodes := make([]models.Episode, 0)

	for _, entry := range entries {
		if entry.IsDir() {
			continue
		}
		name := entry.Name()

		// 跳过 Zone.Identifier 文件（Windows ADS 残留）
		if strings.Contains(name, ":Zone.Identifier") {
			continue
		}

		// 只处理视频文件
		ext := strings.ToLower(filepath.Ext(name))
		if !videoExts[ext] {
			continue
		}

		epNum := extractEpisodeNumber(name)
		if epNum <= 0 || seen[epNum] {
			continue
		}
		seen[epNum] = true

		episodes = append(episodes, models.Episode{
			EpNumber: epNum,
			FilePath: name,
		})
	}

	// 按集数排序
	sort.Slice(episodes, func(i, j int) bool {
		return episodes[i].EpNumber < episodes[j].EpNumber
	})

	return episodes, nil
}

func extractEpisodeNumber(filename string) int {
	for _, pattern := range epPatterns {
		match := pattern.FindStringSubmatch(filename)
		if len(match) >= 2 {
			var num int
			fmt.Sscanf(match[1], "%d", &num)
			if num > 0 {
				return num
			}
		}
	}
	return 0
}
```

### 4.4 番剧数据层 `database/anime.go`

```go
package database

import (
	"database/sql"
	"fmt"

	"fan-web/models"
)

const animeSelect = `
	SELECT id, title, title_cn, bangumi_id, cover, summary, ep_count, file_path, created_at
	FROM animes
`

const episodeSelect = `
	SELECT id, anime_id, ep_number, title, file_path, duration
	FROM episodes
`

// --- Anime ---

func ListAnimes(page, pageSize int, keyword string) ([]models.Anime, int, error) {
	var total int
	offset := (page - 1) * pageSize

	if keyword != "" {
		like := "%" + keyword + "%"
		if err := DB.QueryRow(
			"SELECT COUNT(*) FROM animes WHERE title LIKE ? OR title_cn LIKE ?",
			like, like,
		).Scan(&total); err != nil {
			return nil, 0, err
		}
		rows, err := DB.Query(
			animeSelect+" WHERE title LIKE ? OR title_cn LIKE ? ORDER BY created_at DESC LIMIT ? OFFSET ?",
			like, like, pageSize, offset,
		)
		if err != nil {
			return nil, 0, err
		}
		defer rows.Close()
		return scanAnimes(rows)
	}

	if err := DB.QueryRow("SELECT COUNT(*) FROM animes").Scan(&total); err != nil {
		return nil, 0, err
	}
	rows, err := DB.Query(
		animeSelect+" ORDER BY created_at DESC LIMIT ? OFFSET ?",
		pageSize, offset,
	)
	if err != nil {
		return nil, 0, err
	}
	defer rows.Close()
	return scanAnimes(rows)
}

func GetAnimeByID(id int64) (*models.Anime, error) {
	row := DB.QueryRow(animeSelect+" WHERE id = ?", id)
	return scanAnime(row)
}

func CreateAnime(a *models.Anime) (*models.Anime, error) {
	result, err := DB.Exec(
		`INSERT INTO animes (title, title_cn, bangumi_id, cover, summary, ep_count, file_path)
		 VALUES (?, ?, ?, ?, ?, ?, ?)`,
		a.Title, a.TitleCn, a.BangumiID, a.Cover, a.Summary, a.EpCount, a.FilePath,
	)
	if err != nil {
		return nil, err
	}
	id, err := result.LastInsertId()
	if err != nil {
		return nil, err
	}
	return GetAnimeByID(id)
}

func UpdateAnime(a *models.Anime) error {
	result, err := DB.Exec(
		`UPDATE animes SET title = ?, title_cn = ?, summary = ?, ep_count = ?, file_path = ? WHERE id = ?`,
		a.Title, a.TitleCn, a.Summary, a.EpCount, a.FilePath, a.ID,
	)
	if err != nil {
		return err
	}
	rows, _ := result.RowsAffected()
	if rows == 0 {
		return sql.ErrNoRows
	}
	return nil
}

func DeleteAnime(id int64) error {
	result, err := DB.Exec("DELETE FROM animes WHERE id = ?", id)
	if err != nil {
		return err
	}
	rows, _ := result.RowsAffected()
	if rows == 0 {
		return sql.ErrNoRows
	}
	return nil
}

// --- Episode ---

func ListEpisodesByAnimeID(animeID int64) ([]models.Episode, error) {
	rows, err := DB.Query(episodeSelect+" WHERE anime_id = ? ORDER BY ep_number ASC", animeID)
	if err != nil {
		return nil, err
	}
	defer rows.Close()

	episodes := make([]models.Episode, 0)
	for rows.Next() {
		ep, err := scanEpisode(rows)
		if err != nil {
			return nil, err
		}
		episodes = append(episodes, *ep)
	}
	return episodes, rows.Err()
}

// ReplaceEpisodes 在事务中删除旧集数并插入新集数
func ReplaceEpisodes(animeID int64, episodes []models.Episode) error {
	tx, err := DB.Begin()
	if err != nil {
		return err
	}
	defer tx.Rollback()

	if _, err := tx.Exec("DELETE FROM episodes WHERE anime_id = ?", animeID); err != nil {
		return err
	}

	for _, ep := range episodes {
		if _, err := tx.Exec(
			`INSERT INTO episodes (anime_id, ep_number, title, file_path, duration) VALUES (?, ?, ?, ?, ?)`,
			animeID, ep.EpNumber, ep.Title, ep.FilePath, ep.Duration,
		); err != nil {
			return err
		}
	}

	return tx.Commit()
}

// --- scan helpers ---

func scanAnimes(rows *sql.Rows) ([]models.Anime, int, error) {
	animes := make([]models.Anime, 0)
	for rows.Next() {
		a, err := scanAnime(rows)
		if err != nil {
			return nil, 0, err
		}
		animes = append(animes, *a)
	}
	return animes, 0, rows.Err()
}

func scanAnime(row scanner) (*models.Anime, error) {
	var a models.Anime
	if err := row.Scan(
		&a.ID, &a.Title, &a.TitleCn, &a.BangumiID,
		&a.Cover, &a.Summary, &a.EpCount, &a.FilePath, &a.CreatedAt,
	); err != nil {
		return nil, err
	}
	return &a, nil
}

func scanEpisode(row scanner) (*models.Episode, error) {
	var ep models.Episode
	if err := row.Scan(
		&ep.ID, &ep.AnimeID, &ep.EpNumber, &ep.Title, &ep.FilePath, &ep.Duration,
	); err != nil {
		return nil, err
	}
	return &ep, nil
}
```

### 4.5 番剧处理器 `handlers/anime.go`

```go
package handlers

import (
	"database/sql"
	"strconv"
	"strings"

	"github.com/gin-gonic/gin"

	"fan-web/database"
	"fan-web/models"
	"fan-web/services"
	"fan-web/utils"
)

type AnimeHandler struct {
	bangumi *services.BangumiService
	scanner *services.ScannerService
}

func NewAnimeHandler(bangumi *services.BangumiService, scanner *services.ScannerService) *AnimeHandler {
	return &AnimeHandler{bangumi: bangumi, scanner: scanner}
}

// List 番剧列表（分页 + 搜索）
// GET /api/animes?page=1&page_size=20&keyword=xxx
func (h *AnimeHandler) List(c *gin.Context) {
	page, _ := strconv.Atoi(c.DefaultQuery("page", "1"))
	pageSize, _ := strconv.Atoi(c.DefaultQuery("page_size", "20"))
	keyword := strings.TrimSpace(c.Query("keyword"))

	if page < 1 {
		page = 1
	}
	if pageSize < 1 || pageSize > 100 {
		pageSize = 20
	}

	animes, total, err := database.ListAnimes(page, pageSize, keyword)
	if err != nil {
		utils.Error(c, utils.CodeInternal, "查询番剧列表失败")
		return
	}

	utils.Success(c, gin.H{
		"items":     animes,
		"total":     total,
		"page":      page,
		"page_size": pageSize,
	})
}

// Get 番剧详情
// GET /api/animes/:id
func (h *AnimeHandler) Get(c *gin.Context) {
	id, err := strconv.ParseInt(c.Param("id"), 10, 64)
	if err != nil || id <= 0 {
		utils.Error(c, utils.CodeInvalidParams, "无效的番剧 ID")
		return
	}

	anime, err := database.GetAnimeByID(id)
	if err != nil {
		if err == sql.ErrNoRows {
			utils.Error(c, utils.CodeNotFound, "番剧不存在")
			return
		}
		utils.Error(c, utils.CodeInternal, "查询番剧失败")
		return
	}

	utils.Success(c, anime)
}

type createAnimeRequest struct {
	BangumiID int    `json:"bangumi_id"`
	FilePath  string `json:"file_path"`
}

// Create 添加番剧（从 Bangumi 拉取元数据）
// POST /api/animes  body: {"bangumi_id": 265, "file_path": "Re_Zero"}
func (h *AnimeHandler) Create(c *gin.Context) {
	var req createAnimeRequest
	if err := c.ShouldBindJSON(&req); err != nil {
		utils.Error(c, utils.CodeInvalidParams, "请求参数错误")
		return
	}
	if req.BangumiID <= 0 {
		utils.Error(c, utils.CodeInvalidParams, "bangumi_id 必须大于 0")
		return
	}

	subject, err := h.bangumi.GetSubject(req.BangumiID)
	if err != nil {
		utils.Error(c, utils.CodeInternal, "获取 Bangumi 数据失败: "+err.Error())
		return
	}

	anime := &models.Anime{
		Title:     subject.Name,
		TitleCn:   subject.NameCn,
		BangumiID: subject.ID,
		Cover:     subject.Cover,
		Summary:   subject.Summary,
		EpCount:   subject.TotalEpisodes,
		FilePath:  strings.TrimSpace(req.FilePath),
	}

	created, err := database.CreateAnime(anime)
	if err != nil {
		utils.Error(c, utils.CodeInternal, "创建番剧失败")
		return
	}

	utils.Success(c, created)
}

type updateAnimeRequest struct {
	Title    string `json:"title"`
	TitleCn  string `json:"title_cn"`
	Summary  string `json:"summary"`
	EpCount  int    `json:"ep_count"`
	FilePath string `json:"file_path"`
}

	if err := c.ShouldBindJSON(&req); err != nil {
		utils.Error(c, utils.CodeInvalidParams, "请求参数错误")

	anime := &models.Anime{

		Title:    req.Title,
		TitleCn:  req.TitleCn,
		Summary:  req.Summary,
		EpCount:  req.EpCount,
		FilePath: req.FilePath,
	}
```

```typescript
    {
      path: '/animes/new',
      name: 'anime-add',
      meta: { requiresAuth: true },
      component: () => import('../views/AnimeAddView.vue'),
    },
    {
      path: '/animes/:id',
      name: 'anime-detail',
      meta: { requiresAuth: true },
      component: () => import('../views/AnimeDetailView.vue'),
    },
    {
      path: '/admin/users',
      name: 'admin-users',
      meta: { requiresAuth: true, requiresAdmin: true },
      component: () => import('../views/AdminUsersView.vue'),
    },
    {
      path: '/:pathMatch(.*)*',
      redirect: { name: 'home' },
    },
  ],
})

router.beforeEach(async (to) => {
  const authStore = useAuthStore()
  await authStore.initialize()

  if (to.name === 'login') {
    if (!authStore.isAuthenticated) {
      return true
    }
    return getSafeRedirect(to.query.redirect)
  }

  if (to.meta.requiresAuth && !authStore.isAuthenticated) {
    return {
      name: 'login',
      query: { redirect: to.fullPath },
    }
  }

  if (to.meta.requiresAdmin && !authStore.isAdmin) {
    return { name: 'home' }
  }

  return true
})

function getSafeRedirect(value: unknown) {
  if (typeof value === 'string' && value.startsWith('/') && !value.startsWith('//')) {
    return value
  }
  return { name: 'home' }
}
```

## 8. 注意事项

### 8.1 Bangumi API

- 必须设置 `User-Agent` 请求头，否则可能被拒绝
- 搜索接口 `type=2` 表示只搜索动画类型
- 封面 URL 统一转换为 HTTPS（`http://` -> `https://`），避免混合内容警告
- Bangumi API 偶尔会慢或不可用，10 秒超时后返回错误提示
- 如果 Bangumi 返回的 `total_episodes` 为 0，番剧的 `ep_count` 会是 0，用户可以手动编辑修改

### 8.2 文件扫描

- `file_path` 为空字符串时扫描 `video.root_path` 根目录（测试用例即是此场景）
- `file_path` 填写子目录名时扫描 `video.root_path/file_path` 目录
- `:Zone.Identifier` 文件会被自动过滤（Windows ADS 残留）
- 同一集数编号重复时只保留第一个匹配的文件
- 无法识别集数的文件会被跳过（不报错）
- 扫描操作会**覆盖**旧集数（先删除再插入，在事务中执行）

### 8.3 封面图

- 封面 URL 直接使用 Bangumi 的图片地址，前端 `<img>` 直接引用
- 如果封面加载失败，前端用 `@error` 隐藏图片，显示"无封面"占位
- 未在本地缓存封面图（后续阶段可优化）

### 8.4 路由顺序

- `/animes/new` 必须在 `/animes/:id` **之前**注册，否则 `new` 会被当作 `:id` 参数
- 这一点在 `router/index.ts` 中已正确配置，不要调整顺序

### 8.5 不要做的事

- **不要**实现视频播放功能（阶段四）
- **不要**实现播放进度记录（阶段四）
- **不要**添加 UI 组件库（继续用纯 CSS）
- **不要**修改数据库表结构（阶段一已建好）
- **不要**修改认证相关代码（阶段二已完成）
